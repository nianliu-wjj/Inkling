## 5. 发现的缺陷

1. **`ipc::launcher_show` 同步建窗死锁（阶段二 Task 3 引入，已修）**：主窗口启动台页首次点「呼出浮窗启动台」需 `WebviewWindowBuilder::build()`，同步命令跑在主线程上与事件循环互等——`Inkling Launcher` 句柄出现但停在系统默认位置且从不可见，日志无「呼出搜索窗口」，此后主窗口所有 invoke 挂起、灵动岛开关无响应，Alt+Space 又建出第二个隐藏启动器。与阶段一 `pin_create` 同款。修法：改 `pub async fn`（本记录同批提交）。修复后 run9 已运行该版本，但页内按钮的复验操作未完成。
2. **`settings_save` 同步建窗死锁（既有，阶段四范围）**：「启用灵动岛」由关→开时 `settings_save → island_apply → create_island` 在同步命令里 `build()`，同样死锁（run7 后半段：岛窗停在 (228,228) 隐藏、主窗口 `ShowWindow` 无效）。建议 `settings_save` 改 async 或把建窗投递到异步路径。
3. **偶发原生崩溃（既有，与阶段二改动无关）**：run5 空闲 2h 后 `0xC0000005`（第 6 代全盘扫描 C:\ 中）；run6 启动 +2s `0xC0000005`；run8 启动 +3s `0xC0000409`（fastfail）；三次均发生在「全盘索引开始扫描 C:\」之后，stderr 无 Rust panic 文本 → 来自原生组件（SQLite / WebView2 宿主 / 剪贴板 / 托盘）。临时装过 SEH 未处理异常过滤器（已移除，未提交），对 AV 类可打印模块与偏移，但三次崩溃里两次发生在过滤器装入之前、一次是 fastfail 不经过过滤器。索引库 `launcher-index.db` 1.29 GB / 803k 行 `quick_check` ok。建议：管理员下配置 WER LocalDumps 抓 dmp，或逐个停用全盘索引线程 / 剪贴板轮询做二分。
4. 「索引 N 项」只计内存候选（程序 / UWP / 命令 = 253），全盘文件条数未展示（`FileIndex::count` 未接线，即 dead_code 警告来源）。既有实现，阶段四启动台对齐时处理。
