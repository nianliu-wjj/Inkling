## 4. 中止原因

- **API 配额耗尽**：终端反复出现 `API Error: 403 pre-consume quota failed, user quota: $36.010572, need quota: $38.66…`——子代理派发已不可用（需 `/login` 或充值）。
- **会话上下文接近上限**（97%）。
- **交互环境的一处新障碍**：Claude Code 运行在 VS Code 终端里，**每次执行命令都可能把 VS Code 激活到前台**，压住被测窗口；而按标题激活要跨 shell 传中文（本轮出现过被编码弄坏的情况，`window not found: ˼ά��ͼ`），按标题栏点击又会落进屏幕顶部 120px 的**感应区**里误唤面板（本轮发生过两次）。已为此新增 `.tmp/fg-hwnd.ps1`（按窗口句柄激活），但尚未在完整流程里验证。

## 5. 待用户定夺项（8 条）

**取舍类（3 条）**
1. **中岛居中偏差 ≈320px**（静态流下不可真居中；真居中要让它回 `absolute`，代价是窄窗口下压住左岛尾部，原型本就如此）。**本轮已实测确认**。
2. **公式「确定即关窗」**——照原型（`docs/app.js:1841-1853` 确有 `closeMmModal()`），代价是丢了旧侧栏的连续插入能力。
3. **顶栏浮在画布上**——`view.fit()` 的可用区含被三岛盖住的约 65px（基线也是浮条、本阶段放大了遮挡带）；正解是结构性改动「画布静态化 + 顶栏占位行」。

**记录类（5 条）**
4. **`mindmap-new` label 错配**（既存数据风险）——两个候选修法：首次保存成功也换窗（约 15 行，用户可见的窗口切换），或后端加 label↔noteId 绑定表（独立任务）。**用户已批准现场复现，待续。**

6. 默认主题（打字机）下投影变淡（`--shadow-pop` 的扁平化设计）是否合意。
