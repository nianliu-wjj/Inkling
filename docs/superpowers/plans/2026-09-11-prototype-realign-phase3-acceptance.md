## 4. 发现的问题

1. **主窗口进入「隐藏且外部 ShowWindow 无效」态（run10，未定位）**：启动时可见，按 ⌃⇧Space 呼出面板后主窗口变为不可见，`ShowWindow(SW_SHOW)` 轮询 1s 始终置不上 `WS_VISIBLE`，非 DWM cloak，`IsHungAppWindow` 为假；启动器命令 `show_main` 也未能显示。run9 出现过同样现象。重启后（run11）同样操作序列正常，`show_main` 与外部 ShowWindow 均有效。阶段三未新增任何隐藏主窗口的路径（调用点仅 × 按钮 / 托盘切换 / `panel_open_note` / CloseRequested）。记为待观察；下次复现时用 DevTools 查前端是否调用了 `hideMain`。
2. **`ConfirmPopover` 在列表首张卡片上方被裁切**（面板粘贴板页与主窗口笔记页均如此）：确认态存在且 Esc 可关，但按钮不可见。既有问题，阶段四「删除二次确认浮层」对齐时处理。
3. 验收脚本用 SendKeys 键入英文会被中文 IME 拦截（「p3 archive test」变「拍 archivetest」），改用剪贴板粘贴；面板窗口的 IME 状态与启动器窗口不同。
4. 本轮无崩溃、无 panic；启动期全盘索引扫描期间的偶发原生崩溃（阶段二记录）未复现。
