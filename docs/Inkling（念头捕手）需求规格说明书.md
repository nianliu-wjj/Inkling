## 1. 产品愿景与设计哲学

### 1.1 一句话定位
**Inkling** 是一款常驻系统状态栏、从屏幕顶部中央零延迟滑入的**极简桌面念头捕获工具（Fleet-moment Thought Catcher）**。

### 1.2 核心信条
- **1 秒原则**：从念头产生到文字落屏，时间必须 $< 1$ 秒，且**全程不切换当前工作应用**。
- **安静待命**：零红点、零自启弹窗、零打扰。
- **本地优先**：数据默认存放在本机，用户完全掌控隐私与资产。
- **跨平台一致性**：macOS 与 Windows 体验完全统一（Windows 下无视物理刘海差异，统一从屏幕顶部中央滑入）。

## 2. 核心功能需求（原子粒度拆解）

### 2.1 顶部中央悬浮展开（Core Interaction）
- **触发机制**：
  - **鼠标触顶**：光标移动至屏幕顶部中央（水平居中 $\pm 120\text{px}$，高度 $80\text{px}$ 隐形感应区）悬停超过 $100\text{ms}$ 自动滑出。
  - **全局快捷键**：默认 `Ctrl + Shift + Space`——macOS 与 Windows **统一使用 Control 修饰键**，界面与文档统一记作 `⌃⇧Space`，支持在偏好设置中重新录制。
    - **选型理由**：不采用 `Cmd + Space`（被 macOS Spotlight 占用）与 `Win + Space`（被 Windows 输入法切换占用）；Control 三键组合在两平台的系统占用率最低，可满足 1.2「跨平台一致性」信条，避免同一功能在两个系统上需要用户记两套按键。
    - **冲突检测**：录制新快捷键时必须校验是否与系统级快捷键、以及应用内既有快捷键（启动台呼出、三态切换 `⌃1/2/3`）重复；检测到冲突须**拒绝保存并明示占用方**，不得静默覆盖或注册失败后无提示。
    - **注册失败降级**：系统拒绝注册全局热键时（权限不足或被其他应用抢占），须在偏好设置中以警示态标注该快捷键失效，并保留鼠标触顶 / 灵动岛悬停作为可用的兜底呼出路径。
- **动效与尺寸**：
  - 展开/收起动效：引入专业动画组件库（如 GSAP / Motion One），呈现具有物理弹性（Spring / Ease-out）的流畅滑入（$200\text{ms}$）与滑出（$150\text{ms}$）过渡；用户开启系统「减少动态效果」（`prefers-reduced-motion`）时自动降级为无位移淡入淡出（$80\text{ms}$）。动效**不得阻塞输入焦点获取**——编辑器必须在动画开始时即可接受键盘输入，否则违背 1.2「1 秒原则」。
  - 窗口尺寸：固定宽度 $480\text{px}$，高度根据输入内容自适应（最小 $120\text{px}$，最大 $600\text{px}$）。
  - 视觉样式：无边框（Frameless）、半透明毛玻璃特效（macOS Vibrant / Windows Acrylic/Mica）、细微微光描边（$1\text{px}$ 半透明 Border）。
- **层级规范**：呼出面板**置于所有窗口之上**，包括历史归档主窗口（打开归档时呼出面板仍悬浮其上）。
- **失焦逻辑**：
  - 窗口失去焦点（Blur）时自动收起，支持配置：`立即收起` / `延迟 3 秒收起` / `固定不收起`。
  - **弹窗失焦保护**：当任何编辑弹窗（待办编辑弹窗、标签管理弹窗、剪贴板内容编辑浮框）处于打开状态时，呼出面板**不因失焦而自动收起**（弹窗保存后内容需回显至面板）；全部弹窗关闭后，若鼠标已不在面板区域内，则按配置的延迟策略重新计时收起。

### 2.2 顶部三态圆点切换（Tri-State Navigation）
面板顶部居中呈现 3 枚极简圆点指示器，支持键盘快捷键 `⌃1 / ⌃2 / ⌃3`（Control + 数字，与 2.1 全局快捷键同族修饰键，保持跨平台一致）或鼠标点击无缝切换。

**圆点渲染与无障碍规格（口径约束）**：
- **禁止使用 emoji 字符**（🔴🟡🟢）承担圆点渲染职责——emoji 由系统字体绘制，跨平台字形与尺寸不一致、无法响应 2.7 的主题换肤、也无法参与状态过渡动画。圆点须以**矢量方式渲染**（CSS 背景圆或内联 SVG），颜色取自主题语义令牌（笔记 / 粘贴板 / 待办三色）。
- **状态区分走双通道**：非激活态为 8px 实心圆、不透明度 50%；激活态放大至 10px 并附同色低透明度光环（`box-shadow` 扩散）。以**尺寸 + 光环**双通道区分当前态，不把颜色作为唯一辨识信息（色觉障碍用户同样可辨）。
- **无障碍**：圆点组容器 `role="tablist"`，单枚圆点 `role="tab"` + `aria-selected` + `aria-label`（"笔记模式 / 粘贴板模式 / 待办模式"文字标签），支持 Tab 聚焦、←/→ 方向键切换，`:focus-visible` 须呈现明显焦点环。

三态定义如下：

1. 🔴 **笔记模式（Note Mode）**：
   - **Markdown 即时渲染**：编辑区域默认采用 Markdown 格式，具备 Typora 级别的即时渲染体验（所见即所得，光标移入展示语法标记，移出渲染最终效果）。
   - **归档交互**：支持通过点击界面的「归档/发送」按钮将内容归档为新念头，同时支持快捷键发送。
   - **混合存储策略**：
     - 未归档前，输入停止 $500\text{ms}$ 自动保存至本地 SQLite 数据库作为暂存。
     - 点击按钮归档时，支持主动落盘存储。
     - **超限自动落盘**：当笔记内容超过 **1MB** 时，在归档时自动落盘存储为 `.md` 文件，存放在应用数据目录的 `notes/` 中；不得默认写入项目安装目录或源码目录，SQLite 中仅保留索引与相对路径引用。
   - **标签体系（独立于正文的元数据）**：
     - **标签与正文解耦**：标签**不以 `#标签` 形式存在于文本内容中**；标签作为笔记的独立元数据维护。
     - **展示位置（仅两处）**：
       1. **历史归档页·笔记卡片元数据行**：标签 chips 与时间**同一行**展示，**紧跟在时间之后**；最多展示 **3 个**，超出以「+N」省略按钮聚合，点击展开全部；每个标签最多 **5 个字**，超出省略号截断，鼠标悬浮显示完整标签名。
       2. **呼出面板·笔记编辑区右下角**（归档按钮左侧）：新建时展示草稿标签，编辑已有笔记时展示该笔记标签；点击标签区弹出标签管理弹窗。
     - **卡片正文渲染**：笔记卡片正文按 Markdown 渲染展示（粗体/代码等，与编辑器一致的轻量渲染），不展示源码标记。
     - **无标签占位**：当笔记没有任何标签时，两处位置均显示置灰的「无标签」占位文本；占位**不可删除**（无 ✕ 按钮），点击时弹出标签管理页面。
     - **标签管理弹窗**：标签采用**流式布局**；支持**新增**（输入框回车，上限 5 字、去重）、**修改**（点击标签文字就地编辑）、**删除**标签。
     - **删除二次确认（卡片与管理弹窗一致）**：标签的 ✕ 删除按钮**仅在鼠标悬浮于该标签上时才显示**；首次点击 ✕ 进入「抖动确认态」——目标标签以约 **0.7s/次** 的频率左右抖动并变红，**鼠标悬浮到 ✕ 上时抖动动画立即暂停**；再次点击即删除；3 秒无操作自动退出抖动态。
   - **卡片按钮悬浮显隐（v1.2 统一规范，适用于全部卡片）**：
     - **✕ 删除按钮**：卡片**右上角**，仅占据一个角落位置，**仅鼠标悬浮当前卡片时显示**。
     - **功能按钮组**（置顶/编辑等）：卡片**底部右侧**，仅悬浮当前卡片时显示。
     - 点击 ✕ → 卡片**上方悬浮确认框**（「确认删除该笔记？/ 删除 / 取消」，绝对定位于卡片上方、不占满卡片、不推挤布局），二次确认后删除。

2. 🟡 **粘贴板历史（Clipboard Manager）**：
   - 自动监听系统剪贴板（文本、图片、URL、代码片段），所有数据统一持久化存储在 SQLite 中。
   - **数据保留策略**：最多保存最近 **30 天** 的数据，超出部分自动清理。
   - 列表展示最近捕获的历史条目，**需显示复制时间**；若内容被修改保存，则时间更新为最后一次修改保存的时间。
   - 支持实时模糊搜索（呼出面板与历史归档页均有）。
   - **内容截断**：粘贴板卡片内容**最多展示两行**，超出部分使用省略号截断（呼出面板与历史归档一致）。
   - **双击操作**：双击条目直接执行粘贴，并将该条目置顶。
   - **条目布局（呼出面板·粘贴板列表）**：
     - **左上角**：显示该条目的时间（复制时间 / 最后修改时间）。
     - **右上角**：✕ 删除图标按钮（仅悬浮卡片时显示；点击后**卡片上方悬浮二次确认框**，确认后删除）。
     - **右下角**：操作图标按钮组（仅悬浮卡片时显示）——**粘贴**（写回剪贴板）、**打开链接**（仅链接类型显示）、**编辑**（仅文本类条目显示）、**收藏/置顶**（Pin）。
   - **收藏与置顶**：支持单条 Pin 收藏与置顶管理；置顶条目金色高亮并优先排序。
   - **历史归档页粘贴板条目**：数据类型（文本/链接/代码/图片/富文本）以**彩色标签徽章**包裹展示；置顶条目优先排序并高亮描边；链接类型条目提供**「在默认浏览器中打开」图标按钮**；归档页同样提供搜索框。
   - **置顶（Pin）与编辑为两个独立功能**：置顶直接切换不弹编辑框；编辑弹出文本编辑浮框并回显，保存后替换原文本、时间更新为最后修改时间，不影响置顶状态；仅文本类条目可编辑。

3. 🟢 **待办事项（Quick Todo）**：
   - 所有待办数据统一存储在 SQLite 中；待办与子任务采用**标准树状结构**（一个待办最多 **5** 个子任务，子任务不可再嵌套）。
   - **字段模型（待办与子任务一致，v1.2）**：
     - **任务内容**（必填）。
     - **计划完成时间**（界面仍显示为「完成时间」，必填）：**完成日期 + 完成时刻**两个选择器；是列表归属、排序与逾期判定的唯一时间基准。它表示截止/计划完成时刻，不是用户实际勾选完成的时刻；实际完成时间另存为 `completed_at`。卡片底部以「📅」徽章**常显于标签之后**，点击可直接修改（专用聚焦弹窗）。
     - **提醒时间**（选填）：**完整日期 + 时间**（可早于/晚于完成日期）；留空时使用默认提醒计划（见「提醒」）。
     - **优先级**（高 🔴 / 中 🟡 / 低 🟢）。
     - **标签**（选填）：最多 **3 个**、每个最多 **10 字**、去重；在编辑弹窗内管理（输入回车添加，✕ 删除走抖动二次确认，规则同笔记标签）；卡片**左下角**以 chip 展示，点击 chip 进入编辑。
     - **备注**（选填）：最多 **200 字**；编辑弹窗内提供多行输入框与实时字数计数。卡片上的展示样式由偏好设置配置（见「备注展示样式」）。
   - **创建约束**：创建待办/子任务时，**完成时间不能早于当前时刻**（日期选择器下限锁定为今天，保存时二次校验）；**默认值 = 当前日期 + 1 小时后**。编辑/修改已有事项不设此下限（允许查看历史事项）；历史归档页在历史日期点「新增待办」时默认归入该日期并允许补录（提示「历史日期补录」）。
   - **子任务约束**：子任务的**完成时间不能晚于父待办的完成时间**（违规拦截提示）。
   - **编辑弹窗统一**：修改完成时间、提醒时间、编辑内容、标签、备注统一走该编辑弹窗（原生日期/时间选择器，非文本输入）；「提醒模式」下其余字段只读禁用，仅可修改提醒。
   - **优先级体系**：
     - 三级优先级以**不同颜色徽章**标识（高=红、中=黄、低=绿）。
     - **排序规则（v1.2）**：统一按**完成时间升序 → 优先级高在前**；**已完成的沉底**（仍按完成时间、优先级）。
      - **优先级选择器（v1.2 审查优化）**：点击卡片上的优先级徽章打开锚定式弹出菜单，菜单固定展示「高 / 中 / 低」三个选项，当前优先级以勾选图标、描边和 `aria-selected` 明确标识，不重复创建“当前值卡片”。
        - 弹出菜单默认位于徽章下方并与徽章左边缘对齐；若下方空间不足则整体翻转到上方，不能遮挡当前卡片内容或跨过子任务树；超出窗口边界时向内收缩。
        - 每个选项同时展示优先级文字和颜色圆点（高=红、中=黄、低=绿），颜色不能作为唯一辨识信息；选项点击区域不小于 32×32px，悬浮/聚焦/选中状态有明显对比。
        - 支持键盘：徽章可通过 Tab 聚焦，Enter/Space 打开；↑/↓ 或 Home/End 移动选项，Enter 提交，Esc 或点击外部取消并关闭；关闭后焦点返回徽章。
        - 选择后只修改该待办/子任务的 `priority` 与 `updated_at`，不修改计划时间、提醒、完成状态、父子关系或标签备注；保存成功后关闭菜单、toast 提示并按“计划完成时间升序 → 优先级高在前 → 创建时间升序”稳定重排。保存失败时恢复旧值并提示失败；已完成项仅展示非交互徽章。
        - 父待办与子任务的优先级彼此独立；改变父级优先级不级联子任务，改变子任务优先级也不改变父级。
   - **逾期规则（v1.2，以完成时间为准）**：
     - 未完成且**完成时刻已过** → 逾期：当日列表中**完成时刻已过的当天事项**即时标红（无需等到次日）；查看历史日期时，该日未完成事项均视为逾期。
     - 逾期以**醒目红边+红底+「逾期」标记**提示，标记常显。
     - **逾期置顶**：逾期事项归入当日列表顶部「⚠️ 逾期事项」分区（标注项数），按完成时间、优先级排序；**父待办存在逾期子任务时，父待办连同其全部子任务（含已完成的）整体归入该分区**，已完成子任务置灰且不可修改。
   - **日期视图**：
     - 待办归属日 = 完成时间的日期。历史归档页默认展示**当天**，提供 **‹ / › / 今天** 日期切换控件查询任意日期。
     - **呼出面板的待办页**具备全部能力（优先级/逾期/子任务/标签/备注/重复提醒），但**仅可查看当日待办，不提供日期切换**。
     - **日期与逾期展示口径**：归档页选择历史日期时，只展示归属于该日期的顶级待办，该日期未完成事项均标记为逾期；选择今天或呼出面板时，展示今天事项及此前日期仍未完成的逾期事项，逾期事项置于顶部，未来日期事项不提前进入列表。父待办存在逾期子任务时，父待办及其整棵子任务树进入今天的逾期区；历史日期详情仅展示归属于所选日期的事项。所有日期/时间按用户当前时区解释，跨午夜、夏令时和多设备场景必须使用带时区的时间值比较。
   - **提醒（v1.2）**：
     - **未设置提醒时间**（默认）：在**完成时间前 30 分钟、前 5 分钟、完成时间时刻**各提醒一次。
     - **设置了提醒时间**：**只在该提醒时刻提醒一次**（不再触发默认提醒）。
     - 卡片徽章：已设提醒 → 常显「⏰ 日期 时间」（与完成同日仅显时间），点击徽章打开编辑弹窗（提醒模式）修改；未设置 → 淡色 ⏰ 占位，悬浮提示默认提醒计划，点击可设置。
     - 到期时以**屏幕右上角弹出提醒卡片**形式展示（非系统通知弹窗），支持**直接关闭**或**下拉框选择下次提醒时间**。
     - **重复提醒**常显 🔁 徽章（每天/每周），点击弹出下拉修改循环方式。
       - v1.2 中“重复”只表示同一待办的提醒计划，不自动复制新待办；提醒未被完成或关闭时，按选定周期生成下一次提醒，完成或删除后停止。提醒卡片中的“下次提醒时间”只修改下一次 `remind_at`，不改变计划完成时间。调度器必须记录已触发的提醒实例，避免应用重启或每分钟轮询重复弹出同一实例。
   - **备注展示样式（v1.2，偏好设置可配）**：
     - `图标徽章 + 悬浮`：卡片徽章区显示 📄 图标，悬浮 tooltip 显示完整备注，点击进入编辑。
     - `置灰文本行`：备注以置灰单行文本显示在任务内容下方，超出一行省略号截断，悬浮显示全文，点击进入编辑。
     - `混合模式`（**默认**）：备注 ≤100 字（含）使用文本行；>100 字使用图标徽章。
   - **卡片按钮悬浮显隐（v1.2）**：
     - **✕ 删除按钮**：待办/子任务卡片**右上角**，仅占据一个角落位置，**仅悬浮该卡片自身内容区时显示**；徽章区预留角落空间避免重叠。
     - **悬浮层级隔离**：悬浮待办事项时，其子任务的操作按钮与删除按钮不展示；悬浮子任务时，父级待办的按钮不展示（同一时刻只有被悬浮层级的按钮可见，杜绝误触与显隐抖动）。
     - **底部一行**：**左侧**为标签 chips 与**完成时间徽章**（常显）——完成时间徽章紧跟标签之后，格式「📅 今天 HH:mm」或「📅 M/D HH:mm」，逾期时红色；**点击徽章弹出「修改完成时间」弹窗**（仅完成日期/时刻可编辑，其余字段锁定；子任务不能晚于父待办，保存后列表排序与逾期判定即时更新）；**右侧**为悬浮操作区：⏰ 提醒徽章、＋子任务（仅父级）、✏️ 编辑。
     - **子任务与父级同构**：子任务卡片同样具备左下角标签、完成时间徽章、备注展示与底部右侧操作区（⏰/✏️，无 ＋子任务），仅不显示折叠箭头对应的子任务树。
   - **修改与删除**：
     - 点击 ✕ 不直接删除：**卡片上方悬浮确认框**（「⚠️ 确认删除该待办事项/子任务？/ 删除 / 取消」）二次确认后执行；确认期间删除按钮保持常显。
     - **已完成的待办不允许修改、删除**（编辑/删除/优先级/标签/备注/提醒/完成时间均拦截并 toast 提示），**包括取消勾选恢复未完成**（点击已完成项的 checkbox 拦截提示）；唯一例外：已完成的**父待办**仍可 **＋子任务**——新建未完成子任务后，系统必须在同一事务内将父待办**恢复为未完成**并清空 `completed_at`；新子任务默认计划完成时间 = 当前时间 + 1 小时，不受“不得晚于父级”约束；父待办的 `due_at` 顺延为 `max(原父级 due_at, 新子任务 due_at)`，避免父级重开后因沿用已过去的计划时间而立即逾期。
   - **子任务规则**：
     - 所有子任务完成后，父待办自动完成；子任务完成后排在子级列表末尾。
     - 树连接线（│ ├─ └─）、层级深度渐变、折叠/展开（折叠状态由箭头方向指示）。
     - 卡片不再显示「n/m 子任务」进度计数（v1.2 移除）。

### 2.5 桌面置顶小浮窗（Pin Mechanism）
- 任意一条笔记或待办可点击 `Pin` 按钮脱离主面板。
- 生成一个独立小浮窗常驻桌面角落（默认右下角，可自由拖拽吸附）。
- 浮窗特性：窗口级 `alwaysOnTop`；极简呈现（标题/首行 + 前 50 字）；透明度快捷调节（$30\% \sim 100\%$）；双击浮窗展开即时编辑，修改实时同步回本地数据库或文件。

### 2.6 数据持久化与导出
- **本地存储**：统一采用本地 SQLite（支持 WAL 模式），包含笔记、剪贴板、待办、标签关联、统计和设置表；表名与架构文档保持一致。
  - 待办表字段（v1.2）：内容、带时区的计划完成时间、实际完成时间（可空）、下一次提醒时间（可空）、提醒计划/重复规则、优先级、完成状态、父级引用、更新时间；标签和备注分别通过标签关联及备注字段存储。
  - **草稿归档一致性**：自动保存的草稿必须有稳定的草稿 ID；归档成功后在同一事务/可恢复流程中将草稿提升为正式笔记，失败不得出现“列表已归档但正文丢失”或“同一内容重复归档”。
- **超大笔记落盘路径**：`notes` 目录位于应用数据目录下，以 `.md` 纯文本存储；不得默认写入项目安装目录或项目源码目录。用户选择自定义目录时必须显式授权，并在路径不可用时回退到应用数据目录。
- **导出能力**：支持单条或批量导出为 Markdown / TXT / PDF / 图片 / 网页多种格式。

### 2.8 灵动岛模式（Windows 桌面胶囊，v1.3 新增）
- **定位**：Windows 下顶部中央隐形感应区（见 2.1）的**可视化常驻形态**——以胶囊样式常驻屏幕顶部，空闲时轮播待办，悬停即展开主面板；macOS 保持隐形感应区形态不变（物理刘海区域不做可视化占位），两平台共享同一套呼出交互、动效与快捷键。
- **展示位置**：屏幕顶部**水平居中**、贴近屏幕顶边（位于系统任务栏/菜单栏之下），圆角胶囊（全圆角），毛玻璃质感与主面板一致。
- **尺寸规格**：
  - 默认：宽 $320\text{px}$ × 高 $36\text{px}$。
  - 可调节：拖动胶囊右下角手柄实时调整，宽度水平居中对称伸缩。
  - **边界钳制**：宽 $200\sim480\text{px}$、高 $32\sim56\text{px}$，设置最小值/最大值防止过度放大缩小；钳制即时生效，松手后内容按新高度重排。
- **默认内容：滚动播放待办**：
  - 播放源默认**仅当天未完成待办**（含子任务，子任务以「父级 / 子任务」标注归属）；可在设置中切换为**全部未完成待办**（跨日期，非当天项以 `MM-DD` 日期徽章前缀标识）；排序：**逾期事项优先**，其余按计划完成时间先后。
  - 单条展示：优先级颜色圆点 + 待办文本 + 计划完成时刻；逾期项以红色「逾期 HH:mm」标识。
  - 播放形式：**逐条停留式垂直轮播**。以下两个时间参数含义不同，须严格区分，不可混用：
    - **停留时长**：单条待办静止可读的时间，默认 $3\text{s}$，用户可在偏好设置中调节（见下条「停留时间可设置」）。
    - **切换动画时长**：相邻两条之间轨道位移（`translateY`）的过渡时间，**固定 $450\text{ms}$**（`ease` 缓动），不随停留时长变化，也不对用户开放配置。
    - **回环策略**：一轮（播放范围内全部待办）播完后无缝回环继续下一轮，无限循环；实现上在轨道末尾追加首条副本，回环瞬间以无动画方式重置到首条，使视觉上无跳变感。
    - **边界态**：范围内仅一条时静止展示、不启动轮播；范围内全部完成时展示达成态（🎉 今日待办已全部完成）；范围内无任何待办时展示空闲态占位文案。
  - **停留时间可设置**：每条静止停留默认 $3\text{s}$，设置页可调（$1\sim10\text{s}$，超出自动钳制），即时生效于轮播节奏。
  - **悬停暂停**：鼠标悬停胶囊时轮播暂停，移开后从当前条目继续，便于阅读与点击呼出。
  - 待办增删改、完成/逾期状态变化后**即时刷新**播放内容。
- **呼出与层级**：
  - 悬停胶囊 $100\text{ms}$ 防抖展开主面板（与 2.1 感应区一致）；全局快捷键同样可用。
  - 主面板展开期间灵动岛**自动淡出**（不可点），面板收起后自动恢复，避免与面板遮挡重叠。
- **提醒事件岛内呈现（参考 NetSpeed-Dynamic）**：
  - 待办提醒到达时，岛屿从待办轮播**切换为提醒卡片**（⏰ 脉动图标 + 提醒内容单行省略），轮播暂停；$6\text{s}$ 后或**点击提醒卡片**后恢复轮播。
  - 岛内呈现与右上角提醒浮窗（稍后提醒/关闭）**并存**，互不替代；灵动岛关闭时不呈现。
- **外观个性化（参考 NetSpeed-Dynamic）**：
  - **透明度**：胶囊整体透明度 $30\%\sim100\%$ 可调（默认 $100\%$，设置页滑块即时生效）。
  - **流光边框**：可选 conic 渐变旋转描边（默认关闭，设置页开关即时生效）。
  - **全屏自动隐藏**：检测到前台应用全屏时自动隐藏胶囊，退出全屏后恢复（可开关，默认开启；原型无法真实检测其他应用全屏，仅为规格约束）。
- **设置项**：偏好设置提供「灵动岛」开关（默认开启，关闭后胶囊隐藏、感应区与快捷键呼出不受影响）；「滚动停留时间」（默认 $3\text{s}$，$1\sim10\text{s}$ 可调）；「播放范围」（默认**仅当天待办**，可切换全部未完成）；「透明度」（默认 $100\%$）；「流光边框」（默认关闭）；「全屏自动隐藏」（默认开启）。
- **灵动岛媒体控制能力（参考 NetSpeed-Dynamic，v1.3 进阶扩展）**：

### 2.10 全局启动台（Launcher，v1.3 新增）
- **定位**：借鉴 [Wox](https://github.com/Wox-launcher/Wox) 与 [ZeroLaunch-rs](https://github.com/ghost-him/ZeroLaunch-rs) 的设计，为桌面工作流提供键盘优先、纯粹轻量的**快速启动与跨模块调度中枢**。
- **呼出与关闭**：
  - **全局快捷键**：默认 $\text{Alt}+\text{Space}$（macOS 为 $\text{Option}+\text{Space}$，偏好设置可自定义），按下后在屏幕居中弹出单搜索框并自动聚焦。
    - **占用风险与首启检测**：macOS 下 `⌥Space` 被 Alfred、Raycast 等第三方启动器广泛占用，Windows 下 `Alt+Space` 是系统窗口菜单的默认热键。因此**首次启动时须探测注册结果**：注册失败或检测到冲突时，自动降级到备选组合 `⌃⌥Space`，并在偏好设置中标注实际生效的按键，不得让用户面对一个"按了没反应"的快捷键。
  - **系统托盘入口**：托盘右键菜单中新增「🚀 启动台」选项。
  - **退出方式**：$\text{Esc}$、点击启动台外部区域均立即收起并清空上下文。
- **核心搜索能力**：
  - **应用与系统启动**：索引系统常用应用程序、常用系统设置面板，输入拼音、首字母简拼或英文即时模糊匹配。
  - **Inkling 内部功能直达**：支持输入拼音/别名直达历史归档、待办清单、剪贴板历史、新建思维导图、统计报表、偏好设置等各功能视图。
  - **跨模块内容穿透搜索**：实时模糊匹配笔记（正文、标签、思维导图节点文本）、待办事项（标题、归属日期与优先级），按 $\text{Enter}$ 直接跳转并回显到编辑或详情视图。
  - **简易数学计算器**：以 `=` 前缀显式触发（如 `=128*8`），实时给出计算结果，回车将结果复制到剪贴板。
    - **歧义消解（口径修正）**：**不支持"直接输入表达式自动识别"**——裸表达式与应用名/笔记内容的语义边界不可靠（例如 `1password`、`3-5月复盘` 都会被误判为算式）。计算器必须由 `=` 前缀显式进入，避免在用户搜索应用时抢占首位结果。
    - 支持四则运算、括号、百分号与常见单位换算；表达式非法时在结果区提示「表达式无法解析」，不产生结果项。
- **结果分组、排序与歧义消解**：
  - **分组顺序固定**：① 计算器结果（仅 `=` 前缀时出现，恒定置顶）→ ② 应用与系统命令 → ③ Inkling 功能直达 → ④ 笔记 → ⑤ 待办 → ⑥ 剪贴板历史。分组顺序固定不变，用户可预测焦点落点，形成肌肉记忆。
  - **组内排序权重**：`前缀完全匹配 > 首字母简拼匹配 > 拼音全拼匹配 > 模糊子串匹配`；同权重下按**最近使用时间**与**历史启动频次**加权排序，使高频项自然上浮。
  - **结果数量约束**：每组最多展示 5 条，超出以「显示全部 N 条」末项展开，避免长列表淹没跨组结果。
  - **输入防抖**：输入停止 $120\text{ms}$ 后触发检索，避免逐字符全量查询造成卡顿；单次检索超过 $200\text{ms}$ 未返回时先渲染已就绪的分组，不整体阻塞。
- **交互与键盘流**：
  - **纯键盘操作**：$\uparrow / \downarrow$ 跨分组连续移动焦点（跳过分组标题），$\text{Enter}$ 执行当前焦点项，$\text{Esc}$ 关闭并清空上下文。
  - **无命中态**：无任何结果时展示「无匹配结果，回车以默认浏览器搜索」，回车发起网络搜索；该兜底项**不占用方向键焦点**，避免误触发外部跳转。
  - **状态不残留**：每次呼出均为空输入的干净状态，不保留上次查询词与滚动位置（符合 1.2「安静待命」信条）。

### 2.11 笔记 Zen 专注模式（Zen Writing，v1.3 新增）
- **定位**：编辑已有笔记时的**无干扰写作模式**——将呼出面板全屏化，隐藏一切与当前编辑无关的元素。
- **入口展示约束**：「🧘 Zen」按钮**仅在编辑已有笔记时展示**（从主窗口归档列表 ✏️、日期详情卡片 ✏️ 或启动台打开笔记回显编辑的场景）；**呼出面板新建草稿时不展示**。入口位于面板顶部导航右侧，切换到非笔记模式时隐藏。
- **进入 Zen**：点击后**面板全屏化**（占满整个屏幕、圆角归零、层级升至各编辑弹窗之下）：隐藏三态导航、标签区与暂存状态，仅保留编辑器（字号与行高放大、内容列宽居中约束）与底部「保存修改 / 退出 Zen」按钮；编辑器自动聚焦。
- **退出 Zen**：点击「退出 Zen」、$\text{Esc}$（**优先于收起面板**，一次 Esc 只退一层）、保存修改或面板收起时自动退出；退出后恢复面板原尺寸与全部元素。
- **与编辑流程的关系**：Zen 模式不改变既有编辑/保存语义——`500ms` 防抖暂存、「保存修改」更新原笔记并刷新时间等规则在 Zen 下完全一致。

### 2.12 模块插件化架构与配置（Plugin Architecture，v1.3 新增）
- **定位**：将桌面三大核心形态（灵动岛胶囊、呼出悬浮主面板、思维导图编辑窗口、全局启动台）以**可拔插的内置插件**规范解耦，为后续三方扩展与轻量化定制奠定基础。
- **管理入口**：主窗口左侧边栏新增「🧩 插件」专有页签；展示当前所有已注册的插件列表、版本标识（内置核心徽章）、描述文案、启停开关与「⚙️ 配置」直达按钮。
- **核心插件定义与配置能力**：
  1. **灵动岛插件 (`island`)**：
     - **功能职责**：Windows 桌面胶囊、待办轮播、提醒卡片岛内呈现、尺寸拖拽调节、流光边框；
     - **启停联动**：停用后胶囊立即隐藏并终止后台定时器轮播，启用后恢复；点击「配置」直达偏好设置中的灵动岛高级设置区。
  2. **呼出面板插件 (`panel`)**：
     - **功能职责**：顶部感应区、全局呼出快捷键、三态合一捕获（笔记模式、剪贴板历史、待办清单）；
     - **子插件体系**：将笔记、剪贴板、待办作为三态子插件呈现，便于用户清晰洞察其依赖关系；
     - **启停联动**：停用后呼出面板立即收起，顶部感应区悬停与全局快捷键（⌃⇧Space）静默拦截，避免误触。
  3. **思维导图插件 (`mindmap`)**：
     - **功能职责**：独立编辑窗口、节点编辑、图片/公式/外框/主题等 6 大功能抽屉、大纲复制；
     - **启停联动**：停用后笔记归档列表的「🧠 思维导图」新建按钮即时隐藏，若正在打开的导图窗口自动关闭。
  4. **全局启动台插件 (`launcher`)**：
     - **功能职责**：Alt+Space 单输入框居中呼出、拼音模糊匹配应用与内容穿透检索；
     - **启停联动**：停用后快捷键与托盘启动台菜单项静默失效。

## 3. 非功能性需求（Non-Functional Requirements）

> 第 2 章定义「做什么」，本章定义「做到什么水准才算合格」。以下指标均为**可测量的验收条件**，需求冻结时须逐条确认，不得以"尽量流畅"等主观表述替代。

### 3.1 性能预算（Performance Budget）

1.2 的「1 秒原则」若无量化预算则无法验收。以下为硬性预算，超标即视为缺陷：

| # | 指标 | 预算 | 测量方式 |
| :- | :--- | :--- | :--- |
| 1 | **呼出至可输入延迟**（触发 → 编辑器接受首个字符） | $\le 200\text{ms}$（P95） | 高速录屏逐帧比对 / 埋点时间戳 |
| 2 | 冷启动至托盘就绪 | $\le 1.5\text{s}$ | 进程启动到状态栏图标可交互 |
| 3 | 空闲常驻内存（含灵动岛轮播） | $\le 120\text{MB}$ | 连续运行 8 小时后取样 |
| 4 | 空闲 CPU 占用 | $< 0.5\%$ | 无操作 10 分钟均值 |
| 5 | 剪贴板变更至入库可见 | $\le 100\text{ms}$ | 复制动作到列表出现新条目 |
| 6 | 全库搜索响应（1 万条笔记 + 3 万条剪贴板） | $\le 150\text{ms}$（P95） | 输入停止到结果渲染完成 |
| 7 | 灵动岛轮播与面板动效帧率 | $\ge 55\text{fps}$ | 动画期间帧时间采样 |
| 8 | 热力图渲染（365 格 + tooltip 就绪） | $\le 80\text{ms}$ | 视图切换到可交互 |
| 9 | 思维导图 500 节点布局重算 | $\le 300\text{ms}$ | 结构切换到渲染稳定 |

- **预算归属**：指标 1 是产品生死线——它直接决定「不切换应用即可捕获」的体验是否成立，须优先于任何视觉效果保障；必要时以降级动效换取该指标达标。
- **数据量假设**：性能测试须在上述量级的仿真数据集上进行，不得仅以空库或几十条数据验证。

### 3.2 可访问性（Accessibility，WCAG 2.1 AA 基线）

- **键盘完全可达**：所有交互元素（含卡片悬浮操作按钮、优先级徽章、圆点导航、思维导图工具岛）必须可通过 Tab / 方向键到达并操作。**当前原型中大量以 `<span>` 承担按钮职责的元素均不满足此项**，须补齐 `role="button"`、`tabindex="0"` 与 Enter/Space 激活。
- **焦点可见**：统一 `:focus-visible` 焦点环（2px 强调色 + 2px 偏移），不得使用 `outline: none` 且不提供替代。
- **对比度**：正文与背景对比度 $\ge 4.5:1$，$\ge 18\text{px}$ 或粗体文字 $\ge 3:1$。**2.7 的 30 套主题须逐套通过对比度校验**——浅色系主题（浅色、纸杯蛋糕、柠檬、粉彩、线框等）在半透明毛玻璃背景上极易不达标，须为其单独校准 `--text-dim` 等次级文字令牌。
- **颜色不作为唯一信息通道**：优先级（高/中/低）、逾期状态、日期详情的类别区分，除颜色外必须附带文字标签或形状差异；这是 2.2「双通道」与 2.2 优先级选择器规格的统一要求。
- **悬浮显隐的可达性豁免**：v1.2 规定的"仅悬浮时显示操作按钮"对键盘与触控用户不可达，须补充规则——**元素获得键盘焦点时同样显示**（`:focus-within` 等价于 `:hover`）。
- **动效降级**：尊重系统 `prefers-reduced-motion`，降级为无位移淡入淡出（见 2.1）。
- **悬浮提示不可作为唯一信息载体**：仅靠 `title` 传达的信息（如完整标签名、备注全文）须同时提供键盘可触发的等价途径。

### 3.3 可靠性与降级策略（Reliability & Graceful Degradation）

任何外部依赖失败都不得导致数据丢失或功能静默失效：

| 失败场景 | 降级策略 |
| :--- | :--- |
| SQLite 写入失败 / 数据库被锁 | 内存队列重试（指数退避），并在托盘图标上呈现警示态；连续失败超过 3 次时提示用户并提供草稿导出为文件的出口 |
| 剪贴板监听权限被拒（macOS 隐私限制） | 停止监听但保留其余两态可用，在粘贴板页顶部常驻说明与「前往系统设置授权」引导，不得反复弹窗 |
| 全局热键注册失败 | 见 2.1「注册失败降级」——保留触顶与灵动岛悬停作为兜底路径 |
| 思维导图库加载失败 | 笔记列表中导图卡片降级为**只读大纲文本**展示（由持久化的节点树渲染），不得白屏，且不得因此阻塞其他笔记的正常使用 |
| 超大笔记落盘目录不可写 | 回退至应用数据目录（见 2.6），并提示实际落盘位置 |
| 应用异常退出 | 依赖 SQLite WAL 与 $500\text{ms}$ 防抖暂存，**未归档草稿不得丢失**；重启后自动回显最后一次暂存内容 |

### 3.4 安全与隐私（Security & Privacy）

- **本地优先，零遥测**：默认不发起任何网络请求；无账号、无云端上报。P3 的 WebDAV 同步须为显式选择加入（opt-in），且同步凭据存入系统密钥链（macOS Keychain / Windows Credential Manager），**不得明文落库**。
- **剪贴板敏感内容排除（剪贴板管理器的必备义务）**：监听时必须尊重系统与生态约定，跳过记录被标记为敏感/瞬态的内容，否则会把用户的密码明文写进本地数据库：
  - **macOS**：跳过带 `org.nspasteboard.ConcealedType`（密码管理器标记的机密内容）、`org.nspasteboard.TransientType`、`org.nspasteboard.AutoGeneratedType` 的剪贴板项。
  - **Windows**：跳过含 `ExcludeClipboardContentFromMonitorProcessing` 或 `CanIncludeInClipboardHistory` 为否的剪贴板格式。
  - **兜底**：提供「暂停剪贴板监听」的一键开关与应用黑名单（指定来源应用的复制内容不记录）。
- **数据静态安全声明**：SQLite 默认不加密，须在偏好设置的隐私说明中如实告知"本机任何可读取该文件的程序都能读到剪贴板与笔记内容"，避免用户误以为存在加密保护；是否引入 SQLCipher 列为待决事项（见第 6 章）。
- **导出文件权限**：导出产物权限设为仅当前用户可读写（`0600`），不得落入全局可读目录。
- **外部资源**：原型当前通过 CDN 引入 GSAP 与 `simple-mind-map`。**正式版本必须改为随包内置的本地依赖**——「本地优先」信条不允许核心编辑能力依赖外网可用性，同时也避免向第三方 CDN 泄露使用行为。

### 3.5 跨平台一致性与差异矩阵

1.2 声明「macOS 与 Windows 体验完全统一」，但部分能力受系统 API 限制客观无法对齐，须显式声明差异而非模糊承诺：

| 能力 | macOS | Windows | 说明 |
| :--- | :--- | :--- | :--- |
| 顶部呼出 | 隐形感应区 | 隐形感应区 **+ 灵动岛胶囊** | 灵动岛为 Windows 独有可视化形态（见 2.8）；macOS 因物理刘海不做占位 |
| 毛玻璃质感 | Vibrancy | Acrylic / Mica | 观感存在系统级差异，允许不像素级一致 |
| 状态栏常驻 | `NSStatusBar` | 任务栏托盘 | 左键/右键语义保持一致（见 2.3） |
| 媒体控制与音频可视化 | **不支持** | 支持（WASAPI Loopback） | 2.8 该组能力依赖 Windows 专有 API，macOS 侧须隐藏入口而非置灰空转 |
| 系统通知接管 | 不支持 | 支持（Toast 监听） | 同上 |
| 前台应用全屏检测 | 能力受限 | 支持 | 影响「全屏自动隐藏」，macOS 侧须降级为手动开关 |

- **一致性口径修正**：1.2 的「完全统一」应理解为**交互模型与快捷键统一**，而非**能力集完全相同**；平台独有能力必须在对应平台隐藏入口，不得出现"点了没反应"的死开关。

### 3.6 原型与实现的差异声明

`doc/index.html` 为静态交互演示，以下均为**尚未实现的模拟**，不得作为实现完成度的依据：真实 SQLite 持久化（原型用内存对象与 `localStorage`）、系统剪贴板读写、状态栏/托盘注册、窗口层级与 `alwaysOnTop`、跨平台权限申请、全局热键注册、前台应用全屏检测、WASAPI 音频采集。原型的价值在于验证**交互流程与视觉规格**，功能完备性以本文件第 2 章为准。

## 5. 术语表（Glossary）

本表用于消除文档内长期存在的一词多义。**冻结后不得在其他文档中赋予这些词第二种含义。**

| 术语 | 定义 | 易混淆点（必读） |
| :--- | :--- | :--- |
| **置顶（Pin）** | 用户主动将某条笔记/剪贴板条目**排到列表最前**的状态，字段为 `pinned`；金色高亮标识 | 与「置顶浮窗」（2.5，脱离面板常驻桌面的独立窗口）**不是同一功能**，二者可独立存在 |
| **pin（类别标识）** | ~~历史遗留用法~~，曾在 2.3 / 3.x 中被用来泛指"某日的一条记录" | **已废弃该用法**。日期详情与统计口径统一改称「记录（Record）」，避免与置顶混淆 |
| **计划完成时间（`due_at`）** | 用户设定的**截止/计划完成时刻**（日期 + 时刻），必填；是列表归属、排序与逾期判定的**唯一时间基准** | 界面标签显示为「完成时间」，但它**不是**用户实际勾选完成的时刻。这是全文最易误读的字段 |
| **实际完成时间（`completed_at`）** | 用户实际勾选完成的时刻，由系统写入 | 仅用于统计口径中的"实际完成"事件计数（3.x / 2.4），不参与排序与逾期判定 |
| **逾期（Overdue）** | 未完成且 `due_at` 已过 | 判定基准是 `due_at` 而非自然日切换——当天下午 3 点过期的事项在当天下午 3 点即标红，无需等到次日 |
| **暂存（Draft Autosave）** | 输入停止 $500\text{ms}$ 后自动写入的**草稿**状态，尚未进入笔记列表 | 与「归档」不同：暂存不产生正式笔记，草稿须有稳定草稿 ID（2.6） |
| **归档（Archive）** | 用户主动将草稿提升为**正式笔记**的动作 | 「历史归档」指主窗口的数据浏览视图，是名词；「归档念头」是动作，是动词 |
| **三态（Tri-State）** | 呼出面板内笔记 / 粘贴板 / 待办三个并列模式 | 不是三种窗口，而是同一面板的三个页面（2.2） |
| **感应区（Hotzone）** | 屏幕顶部中央的**隐形**触发区域，两平台均有 | 与「灵动岛」不同：灵动岛是 Windows 独有的**可视化**常驻胶囊（2.8），二者共享同一套呼出逻辑 |
| **插件（Plugin）** | v1.3 起将内置功能模块以可启停单元管理的形态 | 当前**全部为内置插件**，不支持第三方安装；「可拔插」指可启停与独立配置，不等于开放插件市场（2.12） |
| **Zen 模式** | 编辑**已有笔记**时的面板全屏无干扰写作态 | 新建草稿时不提供该入口（2.11） |

### 6.2 产品范围质疑（需产品决策）

- 🔴 **灵动岛媒体控制是否属于本产品范围**：2.8 后半部分（媒体会话控制、WASAPI 音频可视化 5 频段柱状图、系统 Toast 通知接管、注册表配置持久化）与 1.1「**极简**桌面念头捕获工具」的定位存在明显张力：
  - 这组能力与"捕获念头"无因果关系，属于**独立的桌面小工具品类**（其参考项目 NetSpeed-Dynamic 本身即为系统监控工具，而非笔记工具）；
  - 仅 Windows 可实现（见 3.5），会实质性打破 1.2「跨平台一致性」信条；
  - 工程成本高（音频采集、媒体会话协议适配 7 个音乐平台），会挤占 P0–P2 核心体验的打磨预算。
  - **建议**：降级为 P4 候选并明确标注「非承诺范围」（已在第 4 章表格中如此标注），或整体移出本产品，避免需求冻结时被当作既定承诺。
- **思维导图能力边界**：2.9「上百个精美主题」「15 种结构」直接对齐 `wanglin2/mind-map` 完整能力集，但该库的完整能力需大量插件与配置。须确认是**承诺交付**还是**引用上游能力说明**——建议在文档中显式区分"Inkling 承诺范围"与"上游库理论能力"，当前 7 种核心结构为承诺范围。
