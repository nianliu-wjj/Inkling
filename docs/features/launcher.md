# 启动器搜索（Launcher）

全局快捷键呼出的本地搜索框，检索并启动系统程序、UWP 应用、文件与文件夹。全部在本地完成，**不联网、不上传、不采集**。

## 用法

- **呼出 / 收起**：全局快捷键（默认 `Alt+Space`，设置页可改）。再次按下、Esc、或点击别处失焦都会收起。
- **输入即搜**：支持全称、拼音、首字母、大写缩写，打错一两位也能命中（详见「匹配算法」）。
- **键盘操作**：
  - `↑` / `↓` 选择；
  - `Enter` 执行当前动作（默认「打开」）；
  - `Ctrl+Enter` 以管理员身份运行；
  - `Tab` 在「打开 / 管理员 / 打开所在文件夹」间切换动作；
  - `Alt+1..9` 直达对应结果；
  - 空查询时列出最常用 / 最近用的项。

## 数据来源

| 来源 | 内容 |
|---|---|
| 程序 | 公共开始菜单、用户开始菜单、用户桌面下的 `*.exe / *.lnk / *.url`（深度 5，排除含 uninstall / 卸载 / help / 帮助 的项） |
| UWP 应用 | 系统「所有应用」列表（`Get-StartApps`） |
| 文件 / 文件夹 | 用户在设置里配置的根目录（默认：文档 / 下载 / 桌面 / 图片，深度 4） |
| 内置命令 | 打开设置、重建索引、退出 |

索引常驻内存，上限 20 万条；启动时先加载上次快照即可搜索，随后后台全量重扫，此后每 30 分钟重扫一次。设置页可「立即重建」。

## 匹配算法（移植自 ZeroLaunch-rs 的标准引擎）

每个候选先经**关键字生成管道**产出多组小写关键字：归一化（去符号、去空格、去版本号如 `(64-bit)`/`2024`）→ 拼音（连续汉字空格分隔，多音字取前两读音）→ 拼音首字母 → 大写字母缩写。例：

- `微信` → `weixin` / `wei xin` / `wx`
- `Visual Studio Code` → `visualstudiocode` / `vsc`
- `QQ音乐` → `qq yin yue` / `qq yin le`（多音字）/ `qyy` / `qyl`

搜索时逐关键字打分，取最高：

1. **容错门槛**：关键字 ≤2 字符须严格匹配，否则允许输入比关键字多 1 个字符；
2. **编辑距离基础分**：关键字任意后缀与输入的最短编辑距离 `d`，`value = 1 - d/n`，分 `= 3·log2(n+1)·e^(3·value-2)`；
3. **长度比率**（乘）：`3·log2(min(1, 输入长/关键字长) + 1)`；
4. **溢出惩罚**（乘）：输入更长时 `max(0.7, 1 - 0.3·溢出比)`；
5. **子集匹配**（加）：输入字符命中关键字字符多重集的个数；
6. **KMP**（加）：公共前缀长度 +（关键字包含输入时）输入长度；
7. **固定偏移**（加，预留）。

**排序**在引擎分之上叠加使用习惯（`services/launcher/history.rs`）：

- 历史分 `ln(1+启动次数)`×0.8、近 7 天按天加权×1.5、短期热度（`decay=3h`）×0.5；
- **抑制因子** `(基础分/15).clamp(0,1)`：基础匹配分低时习惯加成打折，避免高频程序挤占真正匹配的结果；
- **查询亲和度**：记「查询词 → 最终启动项」，同词再输时加分（权重 3.0、时间衰减、15s 冷却防刷）。

取 Top-9 用 `select_nth_unstable`（不对全量排序），配合 `rayon` 并行打分，中低配设备毫秒级响应。

## 启动方式

一律经 explorer / PowerShell 代理并以**分离进程**启动，被启动的程序不是 Inkling 的子进程，关掉 Inkling 不影响它们：

- 打开：`explorer.exe <path>`；`.lnk` 交系统解析；UWP 用 `shell:AppsFolder\<AppID>`；
- 管理员：`Start-Process -Verb RunAs`（弹 UAC）；
- 打开所在文件夹：`explorer.exe /select,<path>`。

## 设置（偏好设置 → 启动器搜索）

- **全局快捷键（启动器）**：录制式改键，与面板快捷键冲突会被拒绝。
- **索引**：显示条目数与是否重建中，可「立即重建」。
- **文件扫描目录**：增删根目录、调每个目录的扫描深度（1–8）；改动后自动重建索引。

## 数据存放与隐私

- 索引快照 `app_data_dir/launcher/index.json`、使用历史 `app_data_dir/launcher/history.json`；都是本地可再生缓存，不进业务数据库。
- 全程本地，无任何网络请求。

## 代码位置

`src-tauri/src/services/launcher/`：`model`（数据模型）、`keyword`（关键字管道）、`score`（标准引擎）、`history`（习惯加权）、`snapshot`（快照）、`scan`（数据源扫描）、`search`（并行搜索）、`launch`（启动）、`mod`（`LauncherState` + 后台索引线程）。前端 `src/windows/Launcher/LauncherApp.vue`、`src/styles/launcher.css`。

## 已知限制与后续

- **不做全盘文件实时索引**：参考项目也依赖外部 Everything；本期用「可配根目录 + 深度」覆盖日常文件。后续可作为独立子项目接入 Everything（`es.exe` / SDK）或 USN Journal。
- **暂不提取程序图标**：结果以类型图标（🖥/🧩/📄/📁/⚡）区分；图标缓存目录与接口已预留。
- 别名、稳定偏差、语义（AI）搜索、浏览器书签、窗口唤醒等 ZeroLaunch 扩展功能未纳入本期。
